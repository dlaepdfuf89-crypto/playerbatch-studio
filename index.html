No. PlayerBatch Studio is designed as a local Windows production workflow, so the roster-to-render process does not depend on Photoshop.

The built-in production workflow runs locally on the Windows machine, including automatic background removal.

What files go in?

A roster CSV plus PNG or JPG athlete portraits. Clean, consistently framed portraits produce the strongest results.

What comes out?

1080×1350 social PNGs, 2400×3000 print PNGs, and batch delivery files including manifest and failure reporting.

Is there a subscription or paid API?

No recurring subscription or paid API is required for the current release. The product is sold as a one-time purchase.

Which operating system is supported?

The current release is for Windows and uses Microsoft Edge as part of the local workflow.
