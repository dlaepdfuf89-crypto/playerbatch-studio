Local processing matters

For photographers who do not want recurring API costs in the production pipeline, a local Windows workflow can keep the core matching, background-removal, rendering, and export process on the machine.

Templates are not the same as batch production

A template can define the look, but the expensive part of a 30-player job is often repeating the same data entry, image placement, export, naming, and error checking. Batch production targets that repeated work.

PlayerBatch Studio

PlayerBatch Studio accepts a roster CSV and PNG/JPG portraits, matches athletes, flags exceptions, performs local automatic background removal, renders four sports visual systems, and exports social and print PNGs with manifest/failure reporting.

Current platform: Windows. Microsoft Edge is used as part of the local workflow. No Photoshop, recurring subscription, or paid API is required for the current release.
