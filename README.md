# PlayerBatch Studio

**Roster in. Team graphics out.**

PlayerBatch Studio is a local Windows batch-production tool for sports photographers handling Media Day jobs at roster scale.

## What it does

- Import one roster CSV and one portrait folder
- Automatically match athletes to photos
- Review only missing/duplicate/problem cases
- Perform automatic local background removal
- Render four built-in sports visual systems
- Export 1080×1350 social PNGs and 2400×3000 print PNGs
- Deliver the full team in one ZIP with manifest/failure reporting

## Built for

Youth, school, club, and team sports photographers working with roughly 20–100 athletes per job.

## Workflow

Local Windows processing. No Photoshop, cloud account, paid API, or recurring subscription required.
