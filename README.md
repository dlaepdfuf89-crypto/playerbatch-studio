# PlayerBatch Studio

**Roster in. Team graphics out.**

PlayerBatch Studio is a local Windows batch-production tool for youth, school, club, and team sports photographers handling Media Day jobs at roster scale.

## What it does

- Import one roster CSV and one portrait folder
- Automatically match athletes to photos
- Review missing-photo, duplicate-name, long-text, and incomplete-field exceptions
- Perform automatic local background removal
- Render four built-in sports visual systems
- Export 1080×1350 social PNGs and 2400×3000 print PNGs
- Deliver the full team in one ZIP with manifest and failure reporting

## Built for roster-scale sports photography

The workflow is designed for jobs where the same visual system must be personalized across roughly 20–100 athletes without rebuilding every player graphic one at a time.

## Current release

- Windows local workflow
- One-time purchase
- No Photoshop required
- No recurring subscription required
- No paid API required for the built-in production workflow
- PNG and JPG portrait inputs supported
